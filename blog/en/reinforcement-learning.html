Three Building Blocks of Reinforcement Learning

Learning state values, action values, and policies

Nov 6, 2026
Contents

An agent learns by acting in an environment and observing what happens next. The goal is to choose actions that lead to higher expected long-term return. One way to organize the algorithms is to ask what each one learns:

Vπ(s)=Eπ[Gt∣St=s],Qπ(s,a)=Eπ[Gt∣St=s,At=a],π(a∣s)=Pr⁡(At=a∣St=s). \begin{aligned} V^\pi(s) &= \mathbb E_\pi[G_t \mid S_t=s],\\ Q^\pi(s,a) &= \mathbb E_\pi[G_t \mid S_t=s,A_t=a],\\ \pi(a\mid s) &= \Pr(A_t=a\mid S_t=s). \end{aligned} Vπ(s)Qπ(s,a)π(a∣s)​=Eπ​[Gt​∣St​=s],=Eπ​[Gt​∣St​=s,At​=a],=Pr(At​=a∣St​=s).​
  • The state value Vπ(s)V^\pi(s)Vπ(s) estimates the return from a state when the agent follows policy π\piπ.
  • The action value Qπ(s,a)Q^\pi(s,a)Qπ(s,a) estimates the return from taking a particular action first and then following π\piπ.
  • The policy π\piπ specifies how the agent chooses actions.

These three quantities answer different questions. They often appear together: a value estimate can guide an update to the policy that generated the data.

Learning state values

The Bellman equation

In a Markov decision process, the agent takes action AtA_tAt​ in state StS_tSt​, receives reward Rt+1R_{t+1}Rt+1​, and moves to St+1S_{t+1}St+1​. With discount factor γ\gammaγ, the return splits into an immediate reward and a discounted remainder:

Gt=∑k=0∞γkRt+k+1=Rt+1+γGt+1. G_t=\sum_{k=0}^{\infty}\gamma^k R_{t+k+1} =R_{t+1}+\gamma G_{t+1}. Gt​=k=0∑∞​γkRt+k+1​=Rt+1​+γGt+1​.

Conditioning on the current state gives the Bellman expectation equation:

Vπ(s)=Eπ[Rt+1+γVπ(St+1)∣St=s]. V^\pi(s)=\mathbb E_\pi[R_{t+1}+\gamma V^\pi(S_{t+1})\mid S_t=s]. Vπ(s)=Eπ​[Rt+1​+γVπ(St+1​)∣St​=s].

The same recursion leads to different update targets depending on what information is available.

Dynamic programming

If the transition probabilities P(s′∣s,a)P(s'\mid s,a)P(s′∣s,a) and expected rewards r(s,a,s′)r(s,a,s')r(s,a,s′) are known, policy evaluation can average over them explicitly:

Vk+1(s)=∑aπ(a∣s)∑s′P(s′∣s,a)[r(s,a,s′)+γVk(s′)]. V_{k+1}(s)=\sum_a \pi(a\mid s)\sum_{s'}P(s'\mid s,a) \bigl[r(s,a,s')+\gamma V_k(s')\bigr]. Vk+1​(s)=a∑​π(a∣s)s′∑​P(s′∣s,a)[r(s,a,s′)+γVk​(s′)].

Repeated backups propagate information about later rewards to earlier states. This approach assumes access to an environment model.

Monte Carlo

Monte Carlo evaluation learns from sampled episodes. After an episode ends, its rewards give a complete sample GtG_tGt​ for each visited timestep:

V(St)←V(St)+α[Gt−V(St)]. V(S_t)\leftarrow V(S_t)+\alpha[G_t-V(S_t)]. V(St​)←V(St​)+α[Gt​−V(St​)].

With a neural network, the same idea gives the squared-error loss E[(Vϕ(St)−Gt)2]\mathbb E[(V_\phi(S_t)-G_t)^2]E[(Vϕ​(St​)−Gt​)2]. The target uses observed rewards throughout the remainder of the episode. Waiting until the end delays updates, and the return can vary considerably across trajectories.

Temporal-difference learning

TD(0) uses a one-step transition. It adds the observed reward to a discounted estimate of the next state's value:

yt=Rt+1+γV(St+1),δt=yt−V(St),V(St)←V(St)+αδt. \begin{aligned} y_t &= R_{t+1}+\gamma V(S_{t+1}),\\ \delta_t &= y_t-V(S_t),\\ V(S_t)&\leftarrow V(S_t)+\alpha\delta_t. \end{aligned} yt​δt​V(St​)​=Rt+1​+γV(St+1​),=yt​−V(St​),←V(St​)+αδt​.​

Using a value estimate in its own training target is called bootstrapping. It lets the agent update after each transition, at the cost of making the target depend on the current estimates. The value of a terminal state is taken to be zero.

Learning action values

From state values to action choices

For discrete actions, state and action values are related by averaging over what the policy would do:

Qπ(s,a)=E[Rt+1+γVπ(St+1)∣St=s,At=a],Vπ(s)=∑aπ(a∣s)Qπ(s,a). \begin{aligned} Q^\pi(s,a)&=\mathbb E[R_{t+1}+\gamma V^\pi(S_{t+1})\mid S_t=s,A_t=a],\\ V^\pi(s)&=\sum_a\pi(a\mid s)Q^\pi(s,a). \end{aligned} Qπ(s,a)Vπ(s)​=E[Rt+1​+γVπ(St+1​)∣St​=s,At​=a],=a∑​π(a∣s)Qπ(s,a).​

A state value alone does not score each available action. Given the optimal action value Q∗Q^*Q∗, a greedy optimal policy can choose any action in arg⁡max⁡aQ∗(s,a)\arg\max_a Q^*(s,a)argmaxa​Q∗(s,a).

SARSA

SARSA builds its target from the next action actually selected. Its name comes from the five quantities in the update: state, action, reward, next state, and next action.

Q(St,At)←Q(St,At)+α[Rt+1+γQ(St+1,At+1)−Q(St,At)]. Q(S_t,A_t)\leftarrow Q(S_t,A_t)+ \alpha\bigl[R_{t+1}+\gamma Q(S_{t+1},A_{t+1})-Q(S_t,A_t)\bigr]. Q(St​,At​)←Q(St​,At​)+α[Rt+1​+γQ(St+1​,At+1​)−Q(St​,At​)].

This is an on-policy update. If the agent behaves ε\varepsilonε-greedily, the estimated value reflects the exploratory actions it may take later.

Q-learning

Q-learning uses the largest estimated action value at the next state in its target:

Q(St,At)←Q(St,At)+α[Rt+1+γmax⁡a′Q(St+1,a′)−Q(St,At)]. Q(S_t,A_t)\leftarrow Q(S_t,A_t)+ \alpha\bigl[R_{t+1}+\gamma\max_{a'}Q(S_{t+1},a')-Q(S_t,A_t)\bigr]. Q(St​,At​)←Q(St​,At​)+α[Rt+1​+γa′max​Q(St+1​,a′)−Q(St​,At​)].

The behavior policy determines how interactions are collected. The target policy is the policy the update evaluates or improves. Q-learning can collect experience with an exploratory behavior policy while using a greedy target. This makes it off-policy.

DQN and Double DQN

A table becomes impractical when states are high-dimensional, such as raw game frames. A deep Q-network (DQN) uses QθQ_\thetaQθ​ to approximate action values and fits it to a target yyy:

L(θ)=E[(Qθ(s,a)−y)2],y=r+γmax⁡a′Qθ−(s′,a′). \begin{aligned} L(\theta)&=\mathbb E[(Q_\theta(s,a)-y)^2],\\ y&=r+\gamma\max_{a'}Q_{\theta^-}(s',a'). \end{aligned} L(θ)y​=E[(Qθ​(s,a)−y)2],=r+γa′max​Qθ−​(s′,a′).​

The continuation term is zero for terminal transitions. Experience replay samples past transitions in batches, reducing the effect of training on successive, highly correlated observations. The target network with parameters θ−\theta^-θ− changes more slowly than the online network, so the regression target moves less from one update to the next.

Taking the maximum of noisy estimates can favor actions whose values are overestimated. Double DQN separates the choice of action from its evaluation:

a∗=arg⁡max⁡a′Qθ(s′,a′),y=r+γQθ−(s′,a∗). a^*=\arg\max_{a'}Q_\theta(s',a'), \qquad y=r+\gamma Q_{\theta^-}(s',a^*). a∗=arga′max​Qθ​(s′,a′),y=r+γQθ−​(s′,a∗).

The online network selects the action and the target network evaluates it. Slowing the target's updates helps with instability, while the separation in Double DQN addresses maximization bias.

DQN can enumerate the actions when the action space is small and discrete. For continuous actions, such as a vector of joint torques, it is useful to learn a policy that produces an action directly.

Learning policies

Policy gradients and REINFORCE

A stochastic policy πθ(a∣s)\pi_\theta(a\mid s)πθ​(a∣s) is parameterized by θ\thetaθ. For the discounted objective J(θ)=Eπθ[G0]J(\theta)=\mathbb E_{\pi_\theta}[G_0]J(θ)=Eπθ​​[G0​], REINFORCE estimates the gradient from sampled trajectories:

∇θJ(θ)=Eπθ[∑tγt∇θlog⁡πθ(At∣St) Gt]. \nabla_\theta J(\theta)= \mathbb E_{\pi_\theta}\left[ \sum_t\gamma^t\nabla_\theta\log\pi_\theta(A_t\mid S_t)\,G_t \right]. ∇θ​J(θ)=Eπθ​​[t∑​γt∇θ​logπθ​(At​∣St​)Gt​].

Each timestep contributes a score gradient weighted by the return that followed the action. In practice, the sampled returns can be treated as fixed weights when differentiating a loss built from the negative log probabilities. Even for the same action in the same state, sampled returns can vary widely, so the gradient estimate can have high variance.

Baselines and advantage

Suppose two sampled actions yield returns of 10 and 12 from a state whose expected return is 11. Subtracting 11 gives a signal of −1-1−1 for the first sample and +1+1+1 for the second. The update can now distinguish a below-expectation result from an above-expectation one.

In the policy gradient, the weight GtG_tGt​ can be replaced by Gt−b(St)G_t-b(S_t)Gt​−b(St​). A baseline that does not depend on the sampled action leaves the expected gradient unchanged because the conditional expectation of ∇θlog⁡πθ(At∣St)\nabla_\theta\log\pi_\theta(A_t\mid S_t)∇θ​logπθ​(At​∣St​) is zero. Taking b(s)=Vπ(s)b(s)=V^\pi(s)b(s)=Vπ(s) gives the advantage function:

Aπ(s,a)=Qπ(s,a)−Vπ(s). A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s). Aπ(s,a)=Qπ(s,a)−Vπ(s).

Actor-critic

An actor-critic method learns a policy and a value function together. A one-step advantage estimate is the temporal-difference error of the critic:

A^t=Rt+1+γVϕ(St+1)−Vϕ(St). \hat A_t=R_{t+1}+\gamma V_\phi(S_{t+1})-V_\phi(S_t). A^t​=Rt+1​+γVϕ​(St+1​)−Vϕ​(St​).

With an exact value function, the conditional expectation of this quantity given the state and action is the advantage. With a learned critic, it is a bootstrapped approximation. The actor uses that signal to update the policy, and the critic fits the value function to a target:

Lactor=−E[log⁡πθ(At∣St) sg⁡(A^t)],Lcritic=E[(Vϕ(St)−sg⁡(Rt+1+γVϕ(St+1)))2]. \begin{aligned} L_{\mathrm{actor}}&=-\mathbb E[\log\pi_\theta(A_t\mid S_t)\, \operatorname{sg}(\hat A_t)],\\ L_{\mathrm{critic}}&=\mathbb E[(V_\phi(S_t)- \operatorname{sg}(R_{t+1}+\gamma V_\phi(S_{t+1})))^2]. \end{aligned} Lactor​Lcritic​​=−E[logπθ​(At​∣St​)sg(A^t​)],=E[(Vϕ​(St​)−sg(Rt+1​+γVϕ​(St+1​)))2].​

Here sg⁡\operatorname{sg}sg means that the expression is held fixed when differentiating. Advantage actor-critic (A2C) is a practical version that commonly collects data synchronously from multiple environments.

Proximal policy optimization

With data sampled from an older policy, large changes in the action probabilities can make an update unreliable. PPO-Clip compares the current and old probabilities of the sampled action:

ρt(θ)=πθ(At∣St)πθold(At∣St). \rho_t(\theta)=\frac{\pi_\theta(A_t\mid S_t)}{\pi_{\theta_{\mathrm{old}}}(A_t\mid S_t)}. ρt​(θ)=πθold​​(At​∣St​)πθ​(At​∣St​)​.

The objective to maximize is:

LCLIP(θ)=E ⁣[min⁡ ⁣(ρt(θ)A^t, clip⁡(ρt(θ),1−ϵ,1+ϵ)A^t)]. L^{\mathrm{CLIP}}(\theta)= \mathbb E\!\left[\min\!\left( \rho_t(\theta)\hat A_t,\, \operatorname{clip}(\rho_t(\theta),1-\epsilon,1+\epsilon)\hat A_t \right)\right]. LCLIP(θ)=E[min(ρt​(θ)A^t​,clip(ρt​(θ),1−ϵ,1+ϵ)A^t​)].

The clipped objective removes the incentive to move the ratio further in the beneficial direction once it crosses the relevant clipping boundary. Common implementations still train a value critic to help estimate advantages.

Deterministic policies and continuous actions

A deterministic actor outputs an action a=μθ(s)a=\mu_\theta(s)a=μθ​(s). Deterministic policy gradient (DPG) updates the actor by differentiating the critic's score with respect to that action and applying the chain rule:

∇θJ  ∝  Es ⁣[∇aQμ(s,a)∣a=μθ(s)T∇θμθ(s)]. \nabla_\theta J \;\propto\; \mathbb E_s\!\left[ \left.\nabla_a Q^\mu(s,a)\right|_{a=\mu_\theta(s)}^\mathsf{T} \nabla_\theta\mu_\theta(s) \right]. ∇θ​J∝Es​[∇a​Qμ(s,a)∣a=μθ​(s)T​∇θ​μθ​(s)].

The state distribution in the expectation depends on the objective and sampling scheme. Deep deterministic policy gradient (DDPG) pairs a neural actor with a neural critic, uses experience replay and target networks, and injects noise into behavior actions for exploration. The critic uses a target actor to select the next action:

y=r+γQϕ−(s′,μθ−(s′)). y=r+\gamma Q_{\phi^-}(s',\mu_{\theta^-}(s')). y=r+γQϕ−​(s′,μθ−​(s′)).

As in DQN, terminal transitions have no continuation term. Q-value overestimation and unstable updates can still occur. TD3 addresses these problems with changes that include using two critics and delaying actor updates.

Summary

How much is a state worth? Dynamic programming answers using a model, Monte Carlo uses complete sampled returns, and TD learns from shorter transitions plus a value estimate. Which action is worth taking? SARSA evaluates the actions the current policy will actually choose, while Q-learning and its deep variants use greedy targets. How can we improve the decision rule itself? Policy gradient methods adjust the policy directly, often with a critic supplying a more useful learning signal than a raw return.

These ideas meet in generalized policy iteration. Policy evaluation provides information about how the agent is doing, policy improvement changes how it acts, and the improved policy changes what it experiences next.
